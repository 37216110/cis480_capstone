# Source Code

This folder contains reusable Python source code for the capstone project.

## Contents

Source code may include:

- Data cleaning and preprocessing functions
- Data transformation and feature engineering
- Statistical analysis functions
- Machine learning models
- Model evaluation functions
- Data visualization functions
- Utility and helper functions

## Folders

- `cleaning/` - Scripts and functions for cleaning and preparing data.
- `analysis/` - Scripts and functions used for statistical and exploratory analysis.
- `modeling/` - Scripts and functions for building and evaluating models.

Code that becomes reusable or is part of the final analysis workflow should be placed here rather than duplicated across Jupyter notebooks.
